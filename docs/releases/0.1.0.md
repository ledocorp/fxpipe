# fxpipe 0.1.0

**Date:** 12 August 2026  
**Tag:** `v0.1.0`  
**Requires:** [fxlang](https://github.com/ledocorp/fxlang) **v0.9.6+** with **`--cli`** (Win + Linux x86_64)

## Highlights

- First public release of **fxpipe** — parallel BLAKE3 under FsCap via host nursery workers  
- Dual-path bins: `fxpipe` (emit-C) and `fxpipe-ir` (IR)  
- `--workers`, `--stdin`, ordered hex output; deny / missing-file exits documented  
- No author-written `host/*.c` — rebuild with `fx build fxpipe_lib.fx … --cli`  

## Install

Download `fxpipe-0.1.0-windows-x86_64.zip` or `fxpipe-0.1.0-linux-x86_64.tar.gz` from this release.

## Notes

- Needs an fx package that ships `--cli` + `host/cap` + `host/concur` at 0.9.6+.  
- Links BLAKE3 (Apache-2.0 / CC0). See NOTICE.  
- Honest about C workers — not language-level spawn closures.  
- macOS prebuilts are not claimed.
